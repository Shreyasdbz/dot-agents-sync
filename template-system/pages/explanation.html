A stored zero returns without another loader call

The new branch checks whether the cache contains the key. The old branch checks whether the stored value is true.

Inspect the changed condition

Old condition

value = cache.get(key)
if value:
    return value

New condition

if key in cache:
    return cache[key]

Both versions call the loader when the key is absent. Neither version writes to the cache.

Consequences of this branch change

Correctness and product
A stored count of zero becomes a usable result. The application must still decide how to show that count. No product requirement or UI was supplied.
Performance and scaling
The stored-zero case removes one loader call per lookup. Request latency and system throughput were not measured. No workload or paid-call cost was supplied.
Reliability and operations
A stored-zero lookup avoids failures from that loader call. A missing-key lookup can still fail in the loader. Cache freshness and invalidation remain unspecified.
Security and privacy
The change does not alter key construction or access control. Tenant isolation cannot be assessed from this function. Shared tenant caches need evidence from their key owner.
Observability
The functions emit no hit, miss or error signal. Operators cannot identify this branch from a new signal in the supplied code.
Maintainability
The new condition states the presence contract directly. A regression test should distinguish a stored zero from an absent key.

These conclusions follow S1. The security, UI and runtime limits identify missing evidence. They are not claims about a real application.

The loader failure path still exists

  1. Key is absent
  2. Call loader
  3. Loader returns or raises

Both functions return the loader result. Both let a loader exception reach the caller. No retry or recovery owner appears here. Source S1

A membership check followed by a read is not an atomic operation across all cache implementations. Concurrent removal requires a separate contract.

No application checks were executed for this example. The following cases are proposed verification, not passing test results.

  • Store zero. Check that lookup returns zero and the loader is not called.
  • Store seven. Check that lookup returns seven and the loader is not called.
  • Use an absent key. Check that the loader is called once and its result returns.
  • Make the loader raise for an absent key. Check that the same error reaches the caller.
