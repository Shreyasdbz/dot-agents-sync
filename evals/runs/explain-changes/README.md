## Reproduce

Run uv run pytest, uv run ruff check cli tests packages/hooks, uv run ruff format --check cli tests packages/hooks, and python scripts/build_templates.py --check. Validate the new skill with skill-creator's quick_validate.py. Browser checks use NODE_PATH for the host's Playwright and BROWSER_EXECUTABLE_PATH for an installed Chrome-compatible executable: node scripts/test_templates.cjs TEMP_OUTPUT_DIRECTORY. All application-installation tests use temporary homes/projects.

The initial sandbox suite had 169 passes, one profile-selection failure and 17 wheel-build setup errors caused by blocked DNS. The profile expansion was removed to preserve existing profile contracts. The rerun with network access for build dependencies passed all 187 tests in temporary test environments. A final focused catalog/template/guidance run passed 47 tests after metadata updates. Ruff, Ruff formatting, canonical-template parity, diff whitespace checks and skill-creator validation passed. The official STE rules/dictionary were unavailable, so language guidance remains explicitly unverified for exact compliance.
