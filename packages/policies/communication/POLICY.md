# Anti-slop and communication

Lead with the outcome. Use familiar words and concrete evidence. Remove filler, duplicated rationale, invented jargon, fake metrics, private coaching, placeholders, and unsupported completion claims. Each section should change the reader's understanding or decision.

Write each Markdown prose paragraph on one logical source line. Let the viewer wrap text naturally; never hard-wrap to a fixed width or break sentences arbitrarily across source lines. Preserve meaningful paragraph boundaries, lists, tables, code blocks, quotations and intentional line breaks. Do not reflow unrelated existing prose as incidental cleanup.

Use headings and labels that identify the actual subject, date, place, action, state or decision. Omit slogans, poetic travel titles, artificial branding and decorative subtitles. “Tokyo → Kyoto · 9 Apr” conveys information; “Trade the skyline for Kyoto” does not. Prefer compact facts to paragraphs that explain how useful the document is. Keep necessary technical detail; remove repetition rather than flattening important distinctions.
