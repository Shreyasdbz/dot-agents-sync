# ASD-STE100 writing and technical meaning

Write the explanation with ASD-STE100 Simplified Technical English guidance. The official standard has writing rules and a controlled dictionary. Short sentences alone do not establish compliance. Use an authorized official copy and dictionary when available; do not copy the standard into the skill or submit private text to an external checker.

## Write and check

- Use one subject per sentence and one topic per paragraph. State the actor, action, condition and result clearly.
- Use active voice where it preserves meaning. Use direct instructions for actual reader actions; describe system behavior as behavior.
- Target a maximum of 25 words for descriptive sentences and 20 for instructions. Count and split long prose during review; consult the official rules for exact counting conventions. These targets are authoring checks, not a compliance validator.
- Use consistent words for the same meaning. Avoid idioms, metaphors, promotional copy, vague pronouns, dense noun chains and unexplained abbreviations.
- Define necessary technical nouns and verbs at first use and in a compact glossary. Preserve source identifiers, API fields, error codes, literal strings and code. Do not rename them to fit ordinary vocabulary.
- Explain an identifier's meaning in adjacent plain language. Use a short code excerpt only when it clarifies a branch or contract; source code is not STE prose.
- Preserve “must”, “can”, “may” and uncertainty accurately. Do not simplify away a precondition, exception, security boundary or unresolved contradiction.
- Review visible labels, diagrams, captions, alternative text, tables and disclosure content along with body prose. References and source excerpts retain their original wording, marked as source material.

Example: Replace “This robust optimization seamlessly leverages cache semantics” with “The new branch checks whether the key exists.” Then explain the consequence: “A stored zero returns without a loader call.” Do not claim faster requests unless latency was measured.

## State the language check accurately

When the official rules and dictionary were checked, record their issue/date and the checks performed; still avoid an unsupported certification claim. When unavailable, include a short visible note: “This text uses ASD-STE100 writing guidance. The official dictionary was not checked.” Keep the technical explanation complete. Do not promise full compliance based on a model's familiarity, readability score or sentence-length check.
