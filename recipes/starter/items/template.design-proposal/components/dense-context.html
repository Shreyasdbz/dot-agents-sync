Invariants

  • The original operation key is immutable across every retry.
  • A timeout means unknown outcome, not a declined payment.
  • A stale worker cannot overwrite a newer claim.
  • Provider key expiry requires a reconciliation decision.

Compatibility

Old and new workers must agree on key and payload semantics. Preserve existing identities; do not regenerate keys during deployment.

State transitions

Validation

  • Inject failure after provider success and before database commit.
  • Exercise two workers using the same identity.
  • Verify payload matching and retention with the actual provider.
  • Measure retry backlog under an agreed workload.
