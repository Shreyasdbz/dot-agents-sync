# Workspace PR Review context

Private binding contract; no workspace facts are bundled. The authorized source supplies a compact index and maintained repository/vertical topics. Load the index first and only review-relevant topics. Keep methodology in `skill.pr-review`; this context records factual contracts, guidance scope, constraints and evidence.

The index identifies covered repositories, approved topic locations, primary branch/remote identity, ordinary/primary-copy mapping, consumer/provider grants and freshness. Configured copies/roles do not prove fresh checkouts or agent invocation. Record unresolved access, coverage and environment gaps.

Topics describe active entrypoints/dispatch, state ownership, authorization/tenant boundaries, storage/external effects, authoritative shared schemas, callers/consumers, compatibility and rollout/rollback constraints, exercised verification commands and environment-dependent failure paths. Cross-repository contracts name producer, contract and consumers at supported revisions/environment combinations; matching environment labels do not establish deployment compatibility.

For consequential claims retain exact source paths/symbols or approved references, inspected commit/revision, verification date and evidence class: observed, intended, inferred or unknown. Distinguish configuration from execution, local tests from deployments, enforced conventions from examples and measured workload/performance from assumptions. Name changed paths/contract signals invalidating each topic so related authorized work refreshes only affected claims with recoverable provenance.

Keep durable review facts/constraints; omit transient PR findings, code dumps, credentials, customer data and private traces. Redact sensitive evidence, retaining approved references where needed. Stale facts remain labeled until verified; do not advance dates, infer private grants or create competing context stores.
